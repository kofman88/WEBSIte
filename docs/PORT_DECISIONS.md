# Перенос бота в сайт — принятые решения

Контекст: сайт становится самостоятельной реализацией CHM Breaker (свой движок, свои
аккаунты, без зависимости от Telegram-бота во время работы). План переноса и
спецификации подсистем лежат вне репозитория (сессия переноса); здесь — решения,
которые влияют на код.

| # | Решение | Выбор |
|---|---|---|
| D1 | Старые подписчики starter/elite | elite → pro; активный starter → pro до `expires_at`, затем free |
| D2 | Канал реального времени | Поллинг как в Mini App (кэши 30 с + обновление по `visibilitychange`), SSE как улучшение |
| D3 | Графики и share-карточка | Рендер на клиенте (canvas); сервер отдаёт свечи + оверлеи JSON |
| D4 | Telegram-бот как канал | Тот же токен бота для входа через Telegram и уведомлений; Python-бот останавливается при переключении |
| D5 | Биржи автотрейда на старте | Bybit (+demo) и BingX; Binance и OKX за флагом до прогона на песочнице |
| D6 | Какие причуды бота исправляем | Только: `executed=true` при отказе биржи → false; OKX-ветки в BE-мониторе; две гонки истечения → один цикл; `fixed_amount` в процентах; ключи кэша свечей нормализованы; SMC-штраф пересчитывает grade. Всё остальное воспроизводится |
| D7 | Prop Autopilot и настройки AI-фильтра | Логика гейтов переносится (импортированные пользователи сохраняют поведение), UI — только чтение в админке |
| D8 | Импорт данных бота | Пользователи (по Telegram id), подписки, настройки, ключи бирж, сделки, геном, challenge/volume/trend kv |
| D9 | Настройки, доступные в боте только через Telegram-меню | **Расширяем `settings/all`** новыми секциями (LEVELS long/short/shared fine params, SMC advanced, partial TP, risk advanced, notify-флаги, disabled days, fixed amount, vol filter, ui_mode), чтобы на вебе можно было менять всё, что мог менять пользователь бота |
| D10 | Действия, которые были только в Telegram | Переносятся как маршруты `/api/app/*`: закрытие/отмена позиций и ордеров, clear stuck, очистка статистики, сброс настроек, сброс VOLUME-конфига, запуск эволюции генома, стоп-всё, онбординг |
| D11 | Адаптивный оптимизатор | Переносится и потребитель, и производитель (`trade_feedback`, `optimizer_params`, циклы 1 ч / 6 ч); ML-переобучение (XGBoost) не переносится |
| D13 | Механика продукта | Механика Veles поверх трёх стратегий бота: «бот» = стратегия (Уровни/SMC/Объём) с набором параметров; бэктест перед запуском; подбор параметров через Genome; витрина ботов с реальной статистикой трекера; копирование чужого бота в один клик; челлендж как игровой слой. Свободный конструктор (свои условия, сетка/DCA/мартингейл) — отдельным модулем после запуска |
| D14 | Модель оплаты | На выбор пользователя: подписка Pro ($69/30 дн.) или процент с прибыльных сделок с месячным потолком (по PnL биржи) |
| D12 | Не переносится | Guest-режим в чатах, журнал сделок (`/journal`), TON-платежи, Turso-синхронизация, админ-команды Telegram, мониторы метрик бота |

Golden-тесты: `backend/tests/golden` (фикстуры сгенерированы Python-кодом бота, см. там README).

## Продуктовый слой «как Veles, но лучше» (D13) — правила по умолчанию

Полная концепция: `docs/PRODUCT_CONCEPT.md` (исследование Veles, конкуренты, боли пользователей,
экраны, потоки, лендинг, замечания критика). Принятые по умолчанию ответы на её открытые вопросы:

| # | Вопрос | Решение |
|---|---|---|
| Q1 | Сколько ботов у пользователя | Слоты: до 3 ботов, по одному на стратегию (движок не меняется); N ботов — на этапе конструктора |
| Q2 | «За результат» (D14) | 20% чистого реализованного PnL ботов за календарный месяц, с переносом убытка (high-water mark), потолок $69 = цена Pro; в минусовый месяц $0; постоплата; при неоплате — пауза новых входов, позиции не закрываются. Числа в конфиге |
| Q3 | Что входит в «За результат» | Боты на бирже без ограничений Pro; ручные сигналы и анализ — в квотах Free; демо 14 дней на бота |
| Q4 | Награда за онбординг-чеклист | 7 дней Pro за весь чеклист, без денег на баланс |
| Q5 | Публичная лента на лендинге | Задержка 60 минут, уровни скрыты, стопы показываются наравне с тейками |
| Q6 | Боты сообщества на витрине | Позже, после юридической проверки; сейчас только витрина команды |
| Q7 | Термин | «Бот»; «стратегия» = Уровни / SMC / Объём + MA внутри бота |
| Q8 | Старт витрины | Витринные аккаунты запускаются заранее; публичный реестр всех кандидатов с датой запуска |

**Правила честности (обязательны для витрины, лендинга, SEO-страниц):** бумажный трек трекера
подписывается «трек сигналов (бумажный)», не «LIVE»; реальные сделки копий — «биржа»; бэктест геномов
не называется «вне выборки» (по нему шёл отбор) — для сравнения используется только отложенный период;
«walk-forward» не используется, вместо него «проверка стабильности по 4 периодам»; параметры витринного бота
заморожены, правка = новая версия со своим треком; на витрину — после 30 закрытых сигналов **и** 30 дней;
снятые боты уходят в архив; доходность всегда рядом с просадкой и числом сделок, R в % — только с оговоркой
о риске; комиссии вычитаются по модели бэктестера с подписью «оценка»; шкала риска пересчитывается под риск
пользователя; никаких сумм R по платформе и «лучших ботов» без медианы; сравнение со «стандартным DCA-ботом»
— только на честных параметрах (без мартингейла ×2), без бренда конкурентов; планировщик челленджа на
лендинге без цели по умолчанию; калькулятор оплаты с прибылью 0 по умолчанию.
