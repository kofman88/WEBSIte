# Дорожная карта самостоятельного сайта

Сайт — самостоятельная реализация CHM Breaker: свой движок, свои аккаунты, без зависимости от
Telegram-бота. Решения — `docs/PORT_DECISIONS.md`, продуктовая концепция — `docs/PRODUCT_CONCEPT.md`.
Каждая веха проверяется против Python-кода бота (golden-фикстуры, дифференциальные пробы, повторный
прогон независимым агентом) до слияния в ветку `claude/site-standalone-529rg1`.
