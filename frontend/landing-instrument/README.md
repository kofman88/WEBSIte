# Лендинг-прототип «Приборная панель»

Статичный HTML/CSS/JS без сборки. Открыть: `python3 -m http.server -d frontend` → `/landing-instrument/`.

| Файл | Что внутри |
|---|---|
| `index.html` | 13 секций из `docs/PRODUCT_CONCEPT.md` §5.3, SEO-мета и JSON-LD, Яндекс Метрика (`/yandex-metrika.js`), юридические ссылки |
| `css/landing.css` | токены красного Liquid Glass из `frontend/app/app.css` + `--loss` для убытка |
| `js/lib.js` | форматирование по-русски, одометр, SVG-графики с осями и перекрестием, Уилсон, шкала риска, автотеги |
| `js/sections-a.js` | лента тренда BTC, песочница, лента сигналов и счётчики, витрина |
| `js/sections-b.js` | scroll-story, площадка бэктеста, «стоп или усреднение», Genome, планировщик челленджа, калькулятор оплаты |
| `js/api.js` | адаптер данных: мок сейчас, `fetch('/api/public/*')` потом |
| `mock/mock-api.js` | **заглушка, все числа выдуманы**; форма ответов как у будущих `GET /api/public/{trend,stats,feed,showcase,backtest-grid,backtest,genome}` |

Переход на реальные данные: убрать `<script src="mock/mock-api.js">` из `index.html` — `js/api.js`
сам переключится на `fetch` с той же формой ответов, плашка MOCK в шапке и подвале пропадёт.

Правила честности (`docs/PORT_DECISIONS.md`), которые держит разметка: бейдж «трек сигналов (бумажный)»
вместо LIVE; бэктест — только отложенный период, данные отбора затенены и подписаны «завышено»;
медиана по 20 монетам рядом с выбранной; шкала риска пересчитывается под риск посетителя, просадка в %
рядом с доходностью; стопы в ленте наравне с тейками; без суммы R по платформе; архив и реестр кандидатов;
стресс-окна — только как опции, без истории честное «нет данных»; DCA с умеренными параметрами без
мартингейла ×2 и сценарием, где DCA выигрывает; планировщик без цели по умолчанию; калькулятор с прибылью 0.
